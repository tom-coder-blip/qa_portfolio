How I test

A simple, repeatable approach, and a defect format built so nobody has to ask follow-up questions.

  1. Start with the main workflowConfirm the feature works start to finish, the way it's meant to.
  2. Go after the riskiest partsAnything involving money or access gets extra attention: billing, opt-in and opt-out, permissions.
  3. Try to break itInvalid inputs, edge cases and anything that could affect other features.
  4. Re-check related areasRegression: make sure new work didn't break something that used to work.
  5. Report it clearlyWrite test cases as I go and log defects with clear steps so developers can reproduce them fast.
